## 🔧 Workflow & Principles

- **Type-Safe by default** (TS everywhere, strict mode, clean contracts)  
- **DB first** (clear schemas, migrations, indexing, observability)  
- **Pixel-perfect motion** (measured durations, easing maps, reduces jank)
